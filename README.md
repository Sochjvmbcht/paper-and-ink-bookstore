# Paper & Ink — Independent Bookstore

A responsive, single-page bookstore website built for the Mayerfeld Frontend Developer Practicum.

**Live demo:** https://sochjvmbcht.github.io/paper-and-ink-bookstore/

## Project highlights

- Semantic HTML structure and a clear page hierarchy
- Book collections for fiction, nonfiction and staff picks
- Community events section
- Responsive layouts for desktop, tablet and mobile
- In-page navigation between content sections
- CSS layout using Flexbox, Grid, custom properties and media queries

## Technology

- HTML5
- CSS3
- GitHub Pages

This version is a static frontend project. It does not implement a backend, shopping cart, payment processing, account system or database.

## Run locally

No build tools or package installation are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Sochjvmbcht/paper-and-ink-bookstore.git
   cd paper-and-ink-bookstore
   ```

2. Open `index.html` in a browser.

## Accessibility and responsive design

The project uses semantic page structure and responsive CSS techniques. When reviewing the implementation, check keyboard navigation, visible focus states, heading order and layout behaviour at narrow viewport widths.
