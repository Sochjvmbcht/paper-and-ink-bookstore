# Paper & Ink — Independent Bookstore

A responsive, single-page bookstore website created for the Mayerfeld Frontend Developer Practicum.

## Features

- Book collections: fiction, nonfiction, and staff picks
- Community events section
- Responsive layout for desktop, tablet, and mobile
- Working navigation links to page sections

## Technologies

- HTML5 for semantic page structure
- CSS3 with Flexbox, Grid, custom properties, and media queries

## How to Run

Open `index.html` in any web browser. No installation or additional dependencies are required.
